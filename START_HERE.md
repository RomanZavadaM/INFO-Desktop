# INFO Desktop — з чого почати

Це застосунок-редактор для серверів, сумісних з INFO. Окремий продукт зі своїми версіями, випусками й документацією. Українська мова — основна, переклади йдуть за нею.

## Як відновити роботу за кілька хвилин
1. Прочитайте [HANDOFF_CURRENT.md](HANDOFF_CURRENT.md): що зроблено, що не перевірено, **одна наступна дія**.
2. Прочитайте [PROJECT_STATE.md](PROJECT_STATE.md): поточний зріз (замінюється, а не дописується).
3. Прочитайте [PROJECT_RULES.md](PROJECT_RULES.md): що дозволено й що потребує слова власника.
4. Перевірте факти на GitHub, вони головніші за будь-який текст у файлах: гілка `main`, відкриті PR, останні запуски перевірок, список релізів.
5. Журнал дій — [WORKLOG.md](WORKLOG.md) (нове зверху). Стара історія — у `docs/archive/`.

## Ключове коротко
- Стабільна версія: **v0.1.5** (опублікована 05.11.2026), перед нею v0.1.4. Консольний режим входить у 0.1.5.
- Застосунок не має прямого доступу до бази й не користується SSH: лише захищений зв'язок із сервером за правами пристрою.
- Мережу сервера, VPN, файрвол і SSH без окремого слова власника не чіпаємо. Тестових публікацій у Telegram без дозволу не робимо.
- Процес ведеться за стратегією `RomanZavadaM/dev-strategy` (редакція v2), прийнято власником 05.11.2026.

Старі довгі записи (хроніка випусків 0.1.1–0.1.4, чекпойнти) збережені без змін: [START_HERE до 05.11](docs/archive/START_HERE_before_20261105.md), [PROJECT_STATE до 05.11](docs/archive/PROJECT_STATE_before_20261105.md).
