# INFO Desktop

![INFO Desktop checks](https://github.com/RomanZavadaM/INFO-Desktop/actions/workflows/ci.yml/badge.svg)

**INFO Desktop — настільне робоче місце редактора для серверів, сумісних з INFO.** Українська — основна й канонічна мова проєкту; інтерфейс і публічна документація підтримуються сімома мовами.

**Поточна стабільна версія: 0.1.6** (Windows / Linux / macOS) — [завантажити](https://github.com/RomanZavadaM/INFO-Desktop/releases/tag/v0.1.6). Нове: форма першого налаштування. Попередня стабільна: [0.1.5](https://github.com/RomanZavadaM/INFO-Desktop/releases/tag/v0.1.5).

## Завантаження

| Платформа | Файли |
|---|---|
| Windows 10/11 x64 | встановлювач EXE, MSI |
| macOS Apple Silicon | DMG, Portable ZIP |
| macOS Intel x86_64 | DMG, Portable ZIP |
| Linux x64 | AppImage, DEB |

Для кожної платформи є окремий файл контрольних сум `SHA256SUMS-*.txt`. Windows 7 не входить до обов'язкової матриці. Збірки ще не мають завершеної політики підпису, нотаризації й автооновлення.

## Що вміє

- підключення до INFO через `info-desktop-protocol/1`, одноразова реєстрація пристрою;
- ключ пристрою зберігається лише в захищеному сховищі операційної системи;
- канали й повна черга матеріалів, картка матеріалу, джерела, переклади, кешовані медіа;
- редагування заголовка, тексту й каналу; зберегти, пропустити, відкласти, опублікувати;
- ручне створення матеріалу, попередній перегляд у стилі Telegram;
- налаштування через Excel (XLSX): експорт, перевірка без застосування, проба «що зміниться за 48 год», підтверджене застосування, відкат;
- теми: редагування ключових слів і перевірка на прикладі тексту;
- **форма першого налаштування** (з 0.1.6), консольний режим, сім мов інтерфейсу.

Ручні дії редактора йдуть напряму Desktop → API INFO, а не через Excel. XLSX призначений для налаштувань автоматичних правил.

## Форма першого налаштування

Кнопка «Перше налаштування» у верхній панелі працює й без підключення до сервера. Форма питає назву редакції, заголовок бота, значення доступів і канали; під кожним полем є пояснення та приклад, а формат (токен бота, ідентифікатори, адреса каналу `@імʼя`, посилання t.me, сайт, часовий пояс) перевіряється одразу.

Результат — файл `info-first-setup.xlsx` на вашому комп'ютері. **Нічого не надсилається на сервер.** Файл кладуть на сервер (наприклад, `/var/lib/info/inbox/`) і завантажують пунктом 1 меню `info menu`; після застосування файл слід видалити, бо в ньому є значення доступів. Докладніше: [FIRST_SETUP_FORM](docs/FIRST_SETUP_FORM.md). Потрібен сервер INFO `20261116-1300` або новіший.

## Консольний режим

Програма `info-desktop-cli` виконує ті самі дії, що й вікно: черга, «чому в цьому каналі», створення й редагування, публікація, налаштування XLSX (завантаження, перевірка, проба, застосування, відкат), теми. Працює двома способами: через відкрите вікно (галка в застосунку, лише на цьому комп'ютері, ключ не передається) або сама (профіль з'єднання пише вікно, ключ лишається в сховищі ОС). Підтвердження `--yes` потрібне лише для застосування й відкату налаштувань. Інструкція: [CONSOLE_MANUAL](docs/guides/CONSOLE_MANUAL.md).

## Що перевірено

20.10.2026 Desktop підключали до справжнього сервера INFO `20261020-2040`: реальний матеріал створено через Desktop і підтверджено в редакційній черзі та в редакційному боті Telegram (шлях Desktop → API → база → черга). Публічну публікацію в Telegram тоді не виконували. Консольні команди читання перевірені власником на Windows. Форма першого налаштування перевірена лише автоматичними збірками: відкриття створеного файла в Excel і завантаження його на сервері ще не підтверджені.

## Безпека

- немає прямого доступу до SQLite;
- SSH не використовується як прикладний протокол;
- секретів виробничого середовища в репозиторії немає;
- ключ пристрою не зберігається в інтерфейсі чи `localStorage`;
- сервер видає окремі права читання, запису, створення й публікації;
- виробничий шлюз INFO доступний лише через VPN.
