# Форма «Перше налаштування» (локально)

Форма заповнює початковий файл налаштувань INFO на комп'ютері користувача й нічого не надсилає на сервер (не потребує підключення). Результат - `info-first-setup.xlsx`, його кладуть на сервер (наприклад у `/var/lib/info/inbox/`) і завантажують пунктом 1 в `info menu`; значення з аркуша «Доступи» лишаються лише на сервері, файл після завантаження видаляють.

- Структура файлу береться з `src/firstSetupTemplate.json`, зробленого з нейтрального шаблону сервера скриптом `scripts/export_template_json.py` у репозиторії INFO (`import/INFO-template-blank.xlsx`). Оновлювати разом із випуском сервера, якщо змінюється структура аркушів.
- Запис XLSX без залежностей: `src/xlsxWriter.ts` (ZIP без стиснення, рядки як `inlineStr`, формат як у сервера).
- Правила формату полів: `src/firstSetupSchema.ts`; ті самі правила на сервері (`first_setup.py`, `access.py`), сервер перевіряє файл ще раз під час завантаження.
