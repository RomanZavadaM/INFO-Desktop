# INFO Desktop 0.1.1

Premier jalon public stable d’INFO Desktop.

Il comprend la connexion réelle à INFO, l’enregistrement unique du périphérique, le stockage sécurisé des identifiants dans l’OS, la file complète, les vues article/source/média, l’édition, enregistrer/ignorer/report, la création manuelle, l’aperçu Telegram, la publication par scopes, sept langues d’interface, la documentation multilingue et les builds Windows/macOS/Linux.

La validation de production du 20/10/2026 avec LIVE INFO `20261020-2040` a confirmé la création d’un véritable article de Lviv depuis Desktop, visible dans la file éditoriale et le bot Telegram éditorial. Aucun SEND Telegram public n’a été effectué.

L’ukrainien est la langue canonique de la documentation.
