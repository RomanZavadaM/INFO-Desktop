# INFO Desktop 0.1.1

Erster stabiler öffentlicher Checkpoint von INFO Desktop.

Enthalten sind reale INFO-Verbindung, einmalige Geräteregistrierung, sicherer OS-Credential-Speicher, vollständige Pending-Warteschlange, Beitrags-/Quellen-/Medienansicht, Bearbeitung, Speichern/Überspringen/Zurückstellen, manuelles Erstellen, Telegram-Vorschau, scoped Publish, sieben UI-Sprachen, mehrsprachige Dokumentation und Windows/macOS/Linux-Builds.

Die Produktionsabnahme am 20.10.2026 mit LIVE INFO `20261020-2040` bestätigte einen realen Lwiw-Beitrag, der über Desktop erstellt und in der Redaktionswarteschlange sowie im Telegram-Redaktionsbot sichtbar wurde. Kein öffentlicher Telegram-SEND wurde dabei ausgeführt.

Ukrainisch ist die kanonische Dokumentationssprache.
