# INFO Desktop

**INFO Desktop は、INFO 互換サーバー向けの汎用クロスプラットフォーム編集ワークステーションです。**

現在の段階: **0.1.0-dev / 読み取り専用プロトタイプ**。

クライアントはバージョン化されたプロトコルで接続し、実際のサーバーのキュー、本文、メディア、チャンネル、編集状態、関連項目を表示します。最初の段階は厳格な読み取り専用です。

既存の Telegram インターフェースは並行して動作し続けます。

Taxo と同様のビルドモデルを予定しています: Windows 10/11 x64 Setup + Portable、Windows 7 SP1 x64 専用互換 Portable、macOS ARM64、macOS Intel x86_64。
