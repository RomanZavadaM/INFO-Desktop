# INFO Desktop

**INFO Desktop は、INFO 互換サーバー向けの汎用クロスプラットフォーム編集ワークステーションです。**

現在の段階: **0.1.0-dev / 読み取り専用プロトタイプ**。

技術: **Tauri 2 + TypeScript + React**。

主な対象: Windows 10/11 x64、macOS ARM64、macOS Intel x86_64、Linux x64。Windows 7 は新製品の必須対象ではありません。

最初のクライアントは、バージョン化されたプロトコルを通じて実際のキュー、本文、メディアを読み取ります。ネイティブ通信層は GET のみに制限されています。Telegram は並行して動作します。
