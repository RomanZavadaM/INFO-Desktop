# INFO Desktop

**INFO Desktop은 INFO 호환 서버를 위한 범용 크로스플랫폼 뉴스룸 데스크톱 작업 환경입니다.**

현재 단계: **0.1.0-dev / 읽기 전용 프로토타입**.

클라이언트는 버전이 지정된 프로토콜을 통해 연결되며 실제 서버의 대기열, 본문, 미디어, 채널, 편집 상태 및 관련 항목을 표시합니다. 첫 단계는 엄격한 읽기 전용입니다.

기존 Telegram 인터페이스는 병렬로 계속 동작합니다.

Taxo와 같은 빌드 모델을 따릅니다: Windows 10/11 x64 Setup + Portable, Windows 7 SP1 x64 전용 호환 Portable, macOS ARM64, macOS Intel x86_64.
