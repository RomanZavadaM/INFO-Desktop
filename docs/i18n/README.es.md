# INFO Desktop

**INFO Desktop es una estación de trabajo editorial universal y multiplataforma para servidores compatibles con INFO.**

Estado actual: **0.1.0-dev / prototipo de solo lectura**.

Tecnología: **Tauri 2 + TypeScript + React**.

Plataformas principales: Windows 10/11 x64, macOS ARM64, macOS Intel x86_64 y Linux x64. Windows 7 no es un objetivo obligatorio del nuevo producto.

El primer cliente lee cola, textos y medios reales mediante un protocolo versionado. Su transporte nativo solo permite GET. Telegram continúa funcionando en paralelo.
