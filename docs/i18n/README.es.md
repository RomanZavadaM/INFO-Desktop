# INFO Desktop

**INFO Desktop es una estación de trabajo editorial multiplataforma y universal para servidores compatibles con INFO.**

Estado actual: **0.1.0-dev / prototipo de solo lectura**.

El cliente se conecta mediante un protocolo versionado y muestra datos reales del servidor: cola, textos, medios, canales, estado editorial y elementos relacionados. La primera etapa es estrictamente de solo lectura.

La interfaz actual de Telegram continúa funcionando en paralelo.

Modelo de compilación previsto, siguiendo Taxo: Windows 10/11 x64 Setup + Portable, versión Portable separada para Windows 7 SP1 x64, macOS ARM64 y macOS Intel x86_64.
