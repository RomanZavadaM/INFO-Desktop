# INFO Desktop 0.1.2

날짜: 2026-10-22

새로운 기능:
- 항목 카드의 "이 채널에 있는 이유?" 버튼: 이벤트에 대한 모든 채널의 결정과 선택한 채널의 XLSX 조건 트리(INFO 서버 `20261022-2010` 이상 필요);
- 애플리케이션 버전이 이제 머리글에 표시됩니다;
- 체크섬 파일(`SHA256SUMS-*.txt`)이 릴리스 파일과 같은 이름(공백 없음)을 사용하므로 `sha256sum -c`가 이름으로 작동합니다;
- 서버는 작은 이미지에 대해서만 미리보기를 제공합니다(동영상과 큰 파일은 원본 링크로 엽니다).

변경 없음: 프로토콜 `info-desktop-protocol/1`, 등록, 보안. 이 릴리스에서는 Desktop에서의 게시를 테스트하지 않았습니다.
