# INFO Desktop 0.1.2

日付：2026-10-22

新機能：
- 項目カードの「なぜこのチャンネル？」ボタン：イベントに対する全チャンネルの判断と、選択したチャンネルの XLSX 条件ツリー（INFO サーバー `20261022-2010` 以降が必要）；
- アプリケーションのバージョンがヘッダーに表示されるようになりました；
- チェックサムファイル（`SHA256SUMS-*.txt`）はリリースファイルと同じ名前（スペースなし）を使用するため、`sha256sum -c` が名前で動作します；
- サーバーは小さな画像のプレビューのみを提供します（動画や大きなファイルは元リンクから開きます）。

変更なし：プロトコル `info-desktop-protocol/1`、登録、セキュリティ。このリリースでは Desktop からの公開はテストしていません。
