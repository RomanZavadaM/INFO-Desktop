# INFO Desktop — localization

Current language set follows the Taxo product model:

- Ukrainian / `uk`
- English / `en`
- German / `de`
- Spanish / `es`
- French / `fr`
- Korean / `ko`
- Japanese / `ja`

UI language is independent from server instance language, publication-channel language and content language.

All user-facing UI strings belong in locale resources rather than being hard-coded in components.
