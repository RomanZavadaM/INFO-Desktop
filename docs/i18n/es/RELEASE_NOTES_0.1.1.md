# INFO Desktop 0.1.1

Primer checkpoint público estable de INFO Desktop.

Incluye conexión real con INFO, registro único del dispositivo, almacenamiento seguro del sistema operativo, cola pendiente completa, vistas de materiales/fuentes/medios, edición, guardar/omitir/aplazar, creación manual, vista previa de Telegram, publicación por scopes, siete idiomas de interfaz, documentación multilingüe y builds para Windows/macOS/Linux.

La aceptación en producción del 20/10/2026 con LIVE INFO `20261020-2040` confirmó la creación de un material real de Lviv desde Desktop y su aparición en la cola editorial y el bot editorial de Telegram. No se realizó ningún SEND público de Telegram.

El ucraniano es el idioma canónico de la documentación.
