# INFO Desktop

**INFO Desktop est un poste de travail rédactionnel multiplateforme et universel pour les serveurs compatibles INFO.**

État actuel : **0.1.0-dev / prototype en lecture seule**.

Le client se connecte via un protocole versionné et affiche les données réelles du serveur : file d'attente, textes, médias, canaux, état éditorial et éléments associés. La première étape est strictement en lecture seule.

L'interface Telegram existante continue de fonctionner en parallèle.

Modèle de builds prévu selon Taxo : Windows 10/11 x64 Setup + Portable, version Portable séparée pour Windows 7 SP1 x64, macOS ARM64 et macOS Intel x86_64.
