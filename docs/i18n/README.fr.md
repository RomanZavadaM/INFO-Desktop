# INFO Desktop

**INFO Desktop est un poste de travail rédactionnel universel et multiplateforme pour les serveurs compatibles INFO.**

État actuel : **0.1.0-dev / prototype en lecture seule**.

Technologie : **Tauri 2 + TypeScript + React**.

Cibles principales : Windows 10/11 x64, macOS ARM64, macOS Intel x86_64 et Linux x64. Windows 7 n'est pas une cible obligatoire du nouveau produit.

Le premier client lit la file, les textes et les médias réels via un protocole versionné. Le transport natif est limité à GET. Telegram reste un client parallèle fonctionnel.
