## Сумісність та обмеження
- для функцій XLSX/тем потрібен INFO server `20261024-1653` або новіший;
- ручні команди save/skip/defer/publish ідуть безпосередньо до INFO API — XLSX для них не використовується;
- сервер LIVE `20261024-1653` встановлений, проте приймання графічного XLSX workflow на реальному Desktop ще потребує окремої перевірки;
- публічний Telegram SEND із Desktop не тестувався у прийманні;
- signing/notarization/updater поки не впроваджено. Не виконувати налаштувань через нову вкладку без контрольованого приймання.
