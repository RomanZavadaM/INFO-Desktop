# INFO Desktop 0.1.4-rc.1 — тестова версія

**Попередній випуск (pre-release), не стабільний реліз.** Стабільна версія: [0.1.3](https://github.com/RomanZavadaM/INFO-Desktop/releases/tag/v0.1.3).

Що перевіряти:
- Візуальне редагування тексту без HTML-тегів, перемикання на HTML-код.
- Виділення, жирний/курсив/підкреслення, цитати, URL, безпечне вставлення.
- Збереження чернетки, повторне відкриття матеріалу й перехід між новинами.
- У Windows релізний INFO Desktop має запускатися **без постійного вікна консолі**.

Пакети збираються автоматично для Windows, Linux і macOS. Назви містять **0.1.4-rc.1** і супроводжуються SHA256SUMS. У реальному Windows WebView2 UI ще потрібна ручна перевірка. Сервер INFO не змінювався. Не виконувати тестову публікацію в Telegram без окремого дозволу.
