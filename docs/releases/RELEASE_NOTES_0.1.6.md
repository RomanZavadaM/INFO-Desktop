# INFO Desktop v0.1.6

Форма першого налаштування.

## Нове
- Новий екран «Перше налаштування» (кнопка у верхній панелі, працює без підключення до сервера): назва редакції, заголовок бота, значення доступів (токен бота, id адміна, ключі акаунта зчитування) і канали; під кожним полем пояснення та приклад, формат (токен, ідентифікатори, адреса каналу `@імʼя`, посилання t.me, сайт, часовий пояс) перевіряється одразу.
- Форма створює файл налаштувань `info-first-setup.xlsx` на вашому комп'ютері. Нічого не надсилається на сервер. Файл кладуть на сервер (наприклад, `/var/lib/info/inbox/`) і завантажують пунктом 1 меню `info menu`; після застосування його слід видалити, бо в ньому є значення доступів.

## Сумісність
- Працює із сервером INFO `20261116-1300` і новішим: `info menu` показує знайдені файли XLSX і пропонує перше налаштування запитаннями по черзі (пункт 7). Протокол не змінився.
- Будову форми взято з нейтрального серверного шаблону `import/INFO-template-blank.xlsx` (копія в `src/firstSetupTemplate.json`); див. `docs/FIRST_SETUP_FORM.md`.

## Пакети
Windows EXE/MSI, Linux AppImage/DEB, macOS ARM64 і Intel (DMG та Portable ZIP), консольні пакети для тих самих платформ, контрольні суми SHA256.

## Не перевірено
Форму перевірено лише автоматичними збірками; відкриття створеного файла в Excel і завантаження його на сервері власник ще не підтвердив.
