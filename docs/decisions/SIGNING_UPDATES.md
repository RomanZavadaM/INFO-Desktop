# Політика підпису, нотаризації й оновлень (чернетка для рішення власника)

Статус: **чернетка**, внутрішній документ рішень; публічні 7 мов - після ухвалення. Станом на 22.10.2026 збірки Release v0.1.1 **не підписані**.

## Що це означає для користувача зараз
- Windows: SmartScreen показує «Невідомий видавець»; інсталятор запускається після підтвердження.
- macOS: Gatekeeper блокує неперевірений застосунок; відкриття вручну (Open Anyway). Нотаризації немає.
- Linux: підпис не потрібен; AppImage/DEB перевіряються за SHA256.
- Перевірка цілісності: порівняти SHA256 файлу з `SHA256SUMS-<платформа>.txt` **за хешем** (імена в файлах з пропусками, у Release з крапками; буде виправлено).

## Варіанти й вартість
| Що | Спосіб | Вартість |
|---|---|---|
| Оновлення всередині застосунку | Tauri updater: власна пара ключів підпису (minisign, генерується безкоштовно), `latest.json` у GitHub Release | безкоштовно; приватний ключ власник додає як секрет GitHub (`gh secret set`), я його не бачу |
| macOS нотаризація | Apple Developer Program | близько 99 USD на рік (витрата) |
| Windows підпис коду | сертифікат EV/OV або хмарний підпис | платно (від кількох сотень USD на рік); безкоштовний SignPath Foundation лише для відкритих проєктів, а наш код proprietary |

## Рекомендація (Claude Code)
1. Зараз: лишаємо без підпису, поширення через GitHub Release + SHA256; в інструкції користувача пояснити попередження SmartScreen/Gatekeeper.
2. Далі безкоштовно: ввімкнути Tauri updater з власним ключем (оновлення перевіряються підписом ключа, навіть без підпису ОС); тоді нові версії приходять самі.
3. Платний підпис (macOS нотаризація, Windows сертифікат) - окреме рішення власника за правилом «безкоштовно, окрім доменів»; повернутись, коли з'явиться кількість користувачів, для яких попередження ОС є проблемою.

## Потрібне від власника
Підтвердити пункти 1-2 (без витрат) і сказати, чи розглядаємо пункт 3.
