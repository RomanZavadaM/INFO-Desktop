# INFO Desktop — керівництво користувача

## Версії та межі налаштувань

Стабільна версія **0.1.3** вже опублікована з новою вкладкою XLSX та редактором тем. Її можна завантажити у [GitHub Release](https://github.com/RomanZavadaM/INFO-Desktop/releases/tag/v0.1.3). Наскрізне приймання на встановленому Desktop ще належить провести. Сервер INFO `20261024-1653` встановлений, але це не означає, що функцію вже прийнято в установленому Desktop.

Для роботи з XLSX: **експорт → редагування копії → перевірка → проба 48 год → перегляд звіту → підтвердження → застосування**. Якщо після проби завантажити інший XLSX, старий звіт втрачає актуальність. Проба не змінює робочі правила. Відкат стосується останньої серверної зміни, у тому числі зробленої через інший інтерфейс; перевіряйте стан перед відкатом. Уже опубліковані матеріали не видаляються.

Ручні команди редактора **не записуються в XLSX** — вони проходять через API сервера. Публікація потребує дозволу пристрою та окремого приймання перед тестовим публічним SEND.



## Підключення
1. Встановіть INFO Desktop.
2. Оберіть мову інтерфейсу.
3. Імпортуйте виданий адміністратором реєстраційний файл.
4. Після одноразової активації пристрій зберігає секрет у системному secure storage.
5. Натисніть **Підключитися**.

## Робота з чергою
- ліворуч — канали;
- посередині — редакційна черга;
- праворуч — вибраний матеріал;
- доступні джерела, переклади, quality metadata та cached media.

## Редагування
Можна змінити заголовок, текст і канал, після чого натиснути **Зберегти**.

## Дії
Для авторизованого пристрою сервер може дозволити:
- **Пропустити**;
- **+1 година**;
- **Створити** новий матеріал;
- **Опублікувати**.

Доступ визначається server-side scopes. Desktop не обходить серверні права.

## Новий матеріал
Вкажіть заголовок, канал, текст і за потреби URL джерела. Після **Створити** матеріал має з'явитися у звичайній редакційній черзі.

## Безпека
Не передавайте registration file або device credential стороннім. У репозиторії секретів немає.

## Перевірена поведінка
Manual create успішно пройшов production acceptance 20.10.2026. Публічний Telegram SEND у цьому тесті не виконувався.

## Налаштування сервера (XLSX)
Кнопка «Налаштування» в шапці: «Завантажити поточні налаштування» зберігає XLSX; відредагований файл вибирається кнопкою «Вибрати файл XLSX» - сервер лише перевіряє його й показує підсумок; «Застосувати перевірений файл» застосовує його після підтвердження; «Відкотити останнє застосування» повертає попередній стан. Потрібні права `settings.read` і `settings.write` (видаються при реєстрації). Проба «що зміниться за 48 годин» поки виконується на сервері командою `info xlsx try-pending`.

### Проба і теми
«Проба: що зміниться за 48 год» запускає розрахунок на сервері (кілька хвилин) і показує звіт по каналах. Вкладка «Теми»: виберіть тему, відредагуйте слова (`слово*` - початок слова, `слово!` - лише ця форма), перевірте на прикладі заголовка й збережіть; відкат - у «Налаштуваннях».

### Попередження про наслідки
«Налаштування» і «Теми» змінюють правила **живих** каналів: від них залежить, які новини потраплять у Telegram і що публікується автоматично. Опубліковані пости відкат не прибирає. Завжди робіть пробу «що зміниться» перед застосуванням.
