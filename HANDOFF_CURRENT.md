# Передача роботи — станом на 05.11.2026 (після випуску 0.1.5)

Один актуальний запис для того, хто продовжує роботу. Замінюється, коли змінюється факт, потрібний наступному виконавцеві.

## Де ми
- Випущено v0.1.5 (стабільний) з консольним режимом; документація й README 7 мовами оновлені. Проєкт веде за dev-strategy v2.
- Проєкт Б (репозиторій zpidlyady-site) публікує замітки в канали INFO через консоль; це споживач консолі.

## Чого не перевірено
- Приймання редактора на Windows; команди, що змінюють живі правила (`settings probe/apply --yes/rollback --yes`, `themes save`); macOS і Linux; суми файлів релізу, крім Windows-консолі.

## Єдина наступна дія
Власник дивиться випуск і своє приймання на Windows (встановити 0.1.5 з релізу, перевірити редактор і консоль); про результат повідомити.

## Що можна робити далі (вибирає власник)
1. Перевірити команди, що змінюють живі правила (проба, застосування, відкат, збереження тем) лише з окремим дозволом власника на кожну дію.
2. Консоль на сервері без вікна (рішення про ключ пристрою відкладено до оцінки доцільності).
3. Політика підпису застосунку й оновлень.
4. Нові канали для великих тем: власник готовий розглянути (за відчуттям актуальності).

## Чинні обмеження
Секрети не потрапляють у Git і випуски. Без слова власника не робимо: змін на сервері INFO, змін мережі, випусків, видалення без копії. Правила — у `PROJECT_RULES.md`.
